Array Manipulation Questions
====================
1.Reverse an Array: Implement an in-place algorithm to reverse the elements of an array.
2.Find the Largest and Smallest Element: Write a program to find the maximum and minimum values in a given array.
3.Remove Duplicates: Remove duplicate elements from a sorted array (often in-place, returning only unique values).
4.Move All Zeros to the End: Rearrange an array so that all zeros are at the end while maintaining the relative order of the non-zero elements.
5.Rotate an Array: Rotate the array to the left or right by a specified number of positions.
6.Find the Missing Number: Given an array of numbers from 1 to N with one number missing, find that missing number.
7.Maximum Subarray Sum: Find the contiguous subarray within an array that has the largest sum (a classic problem often solved with Kadane's Algorithm).
8.Merge Two Sorted Arrays: Merge two sorted arrays into a single sorted array, often without using extra space.
9.Product of Array Except Self: Given an array nums, return an array output such that output[i] is equal to the product of all the elements of nums except nums[i].
