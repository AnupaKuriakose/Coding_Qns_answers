String Manipulation Questions
=================================================
1.Palindrome Check: Determine if a given string is a palindrome (reads the same forwards and backward).
2.Reverse a String/Words: Reverse the characters in a string, or reverse the order of words in a sentence.
3.Check for Anagrams: Determine if two strings are anagrams of each other (contain the same characters with the same frequencies).
4.Find the First Non-Repeating Character: Find the first character in a string that does not repeat.
5.Longest Substring Without Repeating Characters: Find the length of the longest substring within a given string that does not contain any repeating characters.
6.Implement Atoi: Convert a string to an integer, handling edge cases like whitespace and signs.
7.Longest Palindromic Substring: Find the longest palindromic substring within a given string.
8.Character Frequency: Count the occurrences of each character in a given string, often using a hash map.
9.Remove a Specific Character: Remove all occurrences of a given character from a string.
